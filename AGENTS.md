# Repository guidance

This repository contains user-created and verified skills. Keep each skill self-contained under `skills/<skill-name>/`, preserving its relative references and UI metadata.

After creating and verifying a future skill, ask the user whether to add it to `MohammadGhanaym/baraa_skills`. Wait for that answer before committing or pushing it unless the current request already explicitly authorizes adding that skill. Do not ask again when that approval has already been given for the same addition.

Validate a changed skill with the available skill-creator validator and meaningful checks appropriate to its behavior. Preserve source attribution and distinguish source guidance from technical corrections. Do not bundle original course PDFs, scratch files, credentials, or unrelated skills.
